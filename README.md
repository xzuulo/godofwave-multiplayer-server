# God of Wave — Multiplayer Server

Бэкенд для мультиплеера моей WebGL-игры «Бог волны». Сервер работает на Node.js (ESM) и Express, а за сетевую синхронизацию в реальном времени отвечает библиотека `ws`.

Изначально всё было написано на встроенном модуле `http`, но по мере роста функционала я отрефакторил архитектуру: разделил проект по слоям (роуты, сервисы, вебсокеты), перевёл кодовую базу на ES-модули и добавил Express для удобной обработки HTTP API.

---

## Что делает этот сервер

- **Синхронизация игроков в реальном времени:** бродкаст позиций, действий и состояний персонажей в рамках комнат и уровней с минимальным оверхедом.
- **Комнаты и матчмейкинг:**
  - Создание публичных и приватных лобби с доступом по 4-значному коду.
  - Функция авто-джойна (`AutoJoin`): находит наиболее заполненную, но ещё не забитую до лимита комнату на конкретном уровне, либо на лету поднимает новую.
  - Отслеживание дублирующихся сессий (`ClientId`) с отключением старого сокета при повторном входе.
- **Контроль соединений (Health check):** сервер пингует сокеты каждые 15 секунд, чтобы сразу отсекать мёртвые висячие TCP-коннекты от отключившихся клиентов.
- **Модерация никнеймов:**
  - Интеграция с внешним API проверки текста на ненормативную лексику.
  - Собственный in-memory кэш с TTL (24 часа) и ограничением по размеру: часто используемые и уже проверенные ники отдаются моментально, не расходуя лимиты внешнего сервиса.
- **Служебные API:** реестр активных игровых нод и региональных точек входа на основе входящих периодических пингов.

## Стек технологий

- **Runtime:** Node.js (v18+)
- **Модульная система:** ECMAScript Modules (`type: "module"`)
- **HTTP и сетевой стек:** Express, CORS, WebSocket (`ws`)
- **Окружение:** `dotenv`

## Локальный запуск

1. Склонировать репозиторий:

   ```bash
   git clone https://github.com/xzuulo/godofwave-multiplayer-server.git
   cd godofwave-multiplayer-server
   ```

2. Установить зависимости:

   ```bash
   npm install
   ```

3. Создать файл `.env` в корне (на основе `.env.example`):

   ```env
   PORT=8080
   REGION_ID=spb
   MAIN_TOKEN=your_main_token
   SOURCE_TOKEN=your_source_token
   STATUSNICK_API_URL=https://lf.statusnick.com/api/text/check
   ```

4. Запустить сервер:
   ```bash
   npm start
   ```

## Протокол WebSocket

Клиент взаимодействует с сервером через JSON-сообщения. Основные события:

| Тип (`Type`)   | Параметры                            | Поведение                                                   |
| :------------- | :----------------------------------- | :---------------------------------------------------------- |
| `CreateRoom`   | `MaxPlayers`, `IsPrivate`, `LevelId` | Создаёт комнату с уникальным ID и 4-значным PIN-кодом       |
| `JoinRoom`     | `RoomId`                             | Вход в существующую комнату по ID                           |
| `JoinByCode`   | `Code`                               | Вход в приватную комнату по коду                            |
| `AutoJoin`     | `LevelId`                            | Подбор оптимальной комнаты под уровень или создание новой   |
| `LeaveRoom`    | —                                    | Выход из текущей комнаты с авто-удалением пустого лобби     |
| `pos` / `init` | `RoomId`, `LevelId`, координаты      | Трансляция состояния другим игрокам в комнате или на уровне |
